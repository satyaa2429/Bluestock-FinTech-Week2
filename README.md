3. API Data Extraction Assignment

A public Mutual Fund API was used to demonstrate a complete API data extraction workflow.

The Python program:

Sends an HTTP GET request
Retrieves JSON data
Extracts mutual fund NAV information
Converts the response into a Pandas DataFrame
Cleans date and NAV values
Saves the final data into api_data.csv
Run the API Program
